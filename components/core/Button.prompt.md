VIC-knop voor calls-to-action; gebruik 'link' voor "Zie onze activiteiten"-achtige pijllinks.

```jsx
<Button variant="primary">Neem contact op</Button>
<Button variant="link" href="/bedrijf">Zie onze activiteiten</Button>
```

Varianten: `primary` (groen), `secondary` (donkerblauw), `outline` (groene rand), `link` (groene tekstlink met →). Sizes: `sm` / `md` / `lg`. Copy in zinskast, nooit hoofdletters.
